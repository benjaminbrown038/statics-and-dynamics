# Consistent equations

All lessons use the same headings and symbol tables. Display equations use
`$$` on separate lines, with no blank lines inside a math block. Inline symbols
use single dollar delimiters. Matrices use `\\` as a row separator.

```text
$$
\sum F_y=ma_y,
\qquad \sum M_O=I_O\alpha.
$$
```

These are GitHub Markdown equations. A plain-text editor shows the delimiters;
use a math-capable preview to see the rendered form. The main README repeats
every display equation from all ten lessons, including assumptions and symbols.
Tests check equation coverage, block formatting, and relative document links.
